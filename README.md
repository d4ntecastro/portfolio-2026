# Daniel Ochinyabo — Portfolio

Personal portfolio website built with React + Vite. Features liquid glass UI, smooth animations, and full light/dark mode support.

**Live site:** _coming soon_

## Stack

- React 18
- Vite
- CSS (custom liquid glass design system)

## Sections

- Hero
- About
- Skills
- Projects
- Timeline
- Contact

## Running locally

```bash
npm install
npm run dev
```

## Deploying

```bash
npm run build
```

Then deploy the `dist/` folder to Vercel or Netlify.
